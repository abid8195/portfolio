Calazm — AI Nutrition Companion

Code ↗
Next.jsTypeScriptPrismaPostgreSQL/SQLiteClaude API

An AI-powered nutrition tracker that estimates meals from photos or natural language. The architecture deliberately separates concerns: Claude's vision model never estimates calories directly — it returns a food label, an estimated weight, and a confidence score, and a deterministic resolver computes actual nutrition from a real per-100g database. The model describes, the database quantifies. The app uses three different Claude models for three distinct jobs — vision for photo recognition, a fast model for text normalization, and a larger model for weekly narrative summaries — and falls back gracefully to an offline heuristic if the API is ever unavailable.
